## 3. Features & Agents Added

- **Real Celery task implementations** — bot training (`bot_tasks.py`), document processing (`document_tasks.py`), and website generation (`website_tasks.py`) now contain actual logic instead of placeholder stubs, with durable session handling and failure surfacing.
- **Agent tool executor** — end-to-end tool execution tests covering ownership checks, admin-role gating, and destructive-tool authorization (`tests/test_tool_executor.py`).
- **Agent usage tracking** — agent service now records daily usage and analytic aggregates on interaction, feeding the new frontend dashboards.
- **Bot activity analytics API** — `GET /bots/{bot_id}/analytics` returns a real 14-day `daily_activity` series (conversations/messages per day), replacing a placeholder payload.
- **Frontend analytics dashboards** — bots panel: conversations/messages bar chart from live API data; agents panel: daily-usage area chart and task-outcome bar chart (top-skills and stats cards preserved).

## 4. UI/UX Changes

- `src/modules/bots/AnalyticsPanel.tsx` — replaced "coming soon" placeholder with a recharts bar chart of daily conversations/messages, with an empty-state when no activity exists.
- `src/modules/agents/AgentAnalytics.tsx` — rewritten to show daily task volume as an area chart and task outcomes as a bar chart, alongside the existing top-skills and stat cards.
- No visual regression elsewhere; build verified with `npm run build`.

## 5. Security Improvements

- **DEBUG guardrail** — production/staging boots with `DEBUG=true` are rejected before serving traffic (4 tests in `tests/test_release_checklist.py`).
- **Auth enforcement** — authenticated the previously-open v5 connector, v5 collaboration, and global infrastructure route groups; added 404 semantics for unknown/cross-tenant resources.
- **AI safety** — provider-response hardening prevents crash/leak paths; the prompt-guard/secret-redaction pipeline remains green (input scan, output classification, secret blocking, tool-permission checks).
- **Payments** — Stripe webhook signature handling and checkout flow hardened.
- **CI hygiene** — the lint gate now runs `ruff --select F` on both `app/` and `tests/`, catching dead code/unbound-name regressions on every push.
